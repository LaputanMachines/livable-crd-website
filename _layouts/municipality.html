{%- comment -%} What this page is, in the form a search engine reads it in. The page has been a list of the candidates in one municipality since it was created; until now the only machine-readable thing on it was the site-wide Organization block in _includes/head.html, which says nothing about this page at all. ItemList positions run across the office groups rather than restarting inside each, so the numbering matches the order a reader sees. `name` is the natural "Mehdi Bagheri" rather than the "Bagheri, Mehdi" the list displays: the sorted form is a reading convenience, and it is not what the person is called. Everything is piped through `jsonify`, which quotes and escapes; nothing here is interpolated into the JSON by hand, so a candidate named O'Brien or a municipality with an accent cannot break the block. {%- endcomment -%}
