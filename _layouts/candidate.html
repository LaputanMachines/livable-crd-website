--- layout: default --- {%- comment -%} Per-candidate scorecard page, generated by _plugins/candidate_pages.rb — one per entry in _data/candidates.yml. The plugin resolves the municipality name and the role-qualified standing label, so this template only lays them out. This markup is also the print leaflet. The @media print block in _sass/_candidate.scss restyles it into a one-page black-on-white handout rather than duplicating the candidate's details into a hidden print block — two copies of the same facts would drift apart the first time one is edited. Elements that only make sense on screen (nav, footer, buttons, the back link) are hidden there; the few that only make sense on paper (the wordmark, the spelled-out URLs) are hidden here and revealed there. {%- endcomment -%} {%- assign c = page.candidate -%} {%- assign subjects = site.data.subjects -%} {%- comment -%} Count graded topics up front: the page reads very differently depending on whether anything has come back yet, and right now nothing has for anyone. {%- endcomment -%} {%- assign graded = 0 -%} {%- for subject in subjects -%} {%- assign cell = c.scores[subject.id] | default: "" | strip -%} {%- if cell != "" -%}{%- assign graded = graded | plus: 1 -%}{%- endif -%} {%- endfor -%} {%- comment -%} Print-only masthead, and first in the document so the leaflet opens with it: the site header is navigation and print drops it, but a sheet handed to a stranger on a doorstep has to say who produced it before it says anything else. Hidden on screen, where the real site header is doing this job. The mark plus the title as text, mirroring _includes/header.html, rather than the logo-dark.svg lockup — that file is a near-square stacked badge, so at a masthead's height it came out tiny and sat awkwardly beside the URL. {%- endcomment -%}

The leader is what makes a full-width row readable — without it the grade floats unattached to its topic once the row gets wide. The leader is an empty element rather than a border on the name, because it has to absorb the slack in the row: it is the only flex child that grows, so it stretches to whatever gap a given topic name leaves. aria-hidden because a row of dots is decoration; a screen reader reads "Transit, Grade pending" off the name and the chip's own label. Icons are not lazy-loaded here. They are all above the fold on a page this short, and a lazy image that has not loaded when the reader hits Print leaves a blank square on the leaflet. {%- endcomment -%}
