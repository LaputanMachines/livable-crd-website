--- layout: default --- {%- comment -%} Per-candidate scorecard page, generated by _plugins/candidate_pages.rb, one per entry in _data/candidates.yml. The plugin resolves the municipality name and the role-qualified standing label, so this template only lays them out. This markup is also the print leaflet. The @media print block in _sass/_candidate.scss restyles it into a one-page black-on-white handout rather than duplicating the candidate's details into a hidden print block; two copies of the same facts would drift apart the first time one is edited. Elements that only make sense on screen (nav, footer, buttons, the back link) are hidden there; the few that only make sense on paper (the wordmark, the spelled-out URLs) are hidden here and revealed there. {%- endcomment -%} {%- assign c = page.candidate -%} {%- assign subjects = site.data.subjects -%} {%- comment -%} Counted up front, because the callout at the top has two things it can say and has to pick one: no reply nothing has come back from this candidate reply, nothing out they returned it and no topic has been published yet There used to be a third, for a candidate with some topics published and the rest outstanding, which counted the outstanding ones and explained what the hourglass and the dash meant. The grading key now sits directly above those chips and says the same thing for every candidate, so the callout was a second key in front of the first, restating it in prose. `published` counts topics released with their per-question detail, which is not the same as topics carrying a letter: a topic can be released with its questions before anyone types its top-level grade. {%- endcomment -%} {%- assign returned = c.questionnaire_returned -%} {%- assign gradable = site.data.scores.graded_subjects -%} {%- assign published = 0 -%} {%- for subject in subjects -%} {%- if c.published_subjects[subject.id] -%}{%- assign published = published | plus: 1 -%}{%- endif -%} {%- endfor -%} {%- comment -%} Print-only masthead, and first in the document so the leaflet opens with it: the site header is navigation and print drops it, but a sheet handed to a stranger on a doorstep has to say who produced it before it says anything else. Hidden on screen, where the real site header is doing this job. The mark plus the title as text, mirroring _includes/header.html, rather than the logo-dark.svg lockup: that file is a near-square stacked badge, so at a masthead's height it came out tiny and sat awkwardly beside the URL. {%- endcomment -%}
