{%- comment -%} Banner for scorecards other organizations are publishing about the same candidates. Content comes from _data/other-scorecards.yml so the homepage and the scorecard say the same thing, and so the placeholder becomes a live link by filling in one `url:` rather than by editing two pages. The banner never waits for a URL. Every entry renders; `url` only decides what the last row of the banner offers: blank url - a "not published yet" pill, an optional timing line, and a link to the organization rather than to the scorecard. set url - a button through to the scorecard itself. Renders nothing when the data file has no entries.
