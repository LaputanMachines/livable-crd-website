Voting places, advance voting days, mail-ballot rules and the official candidate list are set by each municipality's Chief Election Officer and published by that municipality. This site is not the authority on any of them, so both /resources/ pages that raise the question end by handing the reader to the office that answers it. Sourced from `elections_url` in _data/municipalities.yml, the same field the municipality indexes link from, so there is one copy of each URL to keep right. A municipality with no URL on file is left out rather than named: this is navigation, and a row that goes nowhere is not.
