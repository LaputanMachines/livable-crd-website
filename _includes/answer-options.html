{%- comment -%} A candidate's answer to a question that offers options to pick from, drawn as the whole list of options with the ones they picked marked, so a reader sees what was on offer as well as what was chosen. Used by _layouts/candidate.html for graded and ungraded questions alike. Params: q the candidate's answer, from _data/scores.yml (answer, selected) asked the question, from _data/questions.yml (type, options, option_limit) name optional; the candidate's name for the label above the list What counts as picked, by where the sheet put it: - `selected`, where sync-questionnaire.py split a multi-select out. An "Other: ..." entry in it marks the form's own "Other" option and is listed after the options with what the candidate typed. - Otherwise, for a multi-select, the "Selected; a; b; Other; typed text" line the sheet appends to `answer`. Several housing questions arrive only this way. - For a single choice, the first line of `answer`. A "pair" question puts a typed follow-up on the lines after it, which is still shown as text. A single choice whose answer is none of the options is typed text in place of one, which marks the "Other" option where the question has one. A question with `follow_up_options` (CLI-01) asks a second thing, offered only after some answers to the first. The pick from it is the answer's "Follow-up: " line, and it gets a list of its own under the first, drawn the same way. Where the line is absent the follow-up was never put to them, so no second list is drawn. The typed text is shown under the list only where it says something the list does not: free text in place of an option, or a follow-up. A multi-select whose picks were read is not repeated as a paragraph of commas. {%- endcomment -%} {%- assign ao_multi = false -%} {%- if include.asked.type contains "multi" -%}{%- assign ao_multi = true -%}{%- endif -%} {%- assign ao_answer = include.q.answer | default: "" -%} {%- assign ao_lines = ao_answer | split: " " -%} {%- assign ao_first = ao_lines | first | strip -%} {%- assign ao_last = ao_lines | last | default: "" -%} {%- comment -%} The candidate's picks, and any "Other" text, from either source. {%- endcomment -%} {%- assign ao_parsed = false -%} {%- assign ao_other = "" -%} {%- assign ao_picks = "" | split: "" -%} {%- if include.q.selected.size > 0 -%} {%- assign ao_picks = include.q.selected -%} {%- assign ao_parsed = true -%} {%- for picked in ao_picks -%} {%- assign ao_head = picked | slice: 0, 7 -%} {%- if ao_head == "Other: " %}{% assign ao_other = picked | remove_first: "Other: " %}{% endif -%} {%- endfor -%} {%- elsif ao_multi and ao_last contains "Selected;
